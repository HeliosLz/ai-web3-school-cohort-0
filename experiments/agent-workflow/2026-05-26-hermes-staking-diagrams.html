Hermes Staking Deposit — 流程图

2026-05-26 · ETH solo staking 的一次 32 ETH deposit · 配套设计文档见 taskgraph.md

1. Task Graph（节点 + 依赖 + 停止条件）

缝在 generate_plan → HUMAN GATE 之间；Auditor 住在 risk_summary 节点，把人看不懂的计划翻成可判风险的摘要。STOP 都是安全终态。

2. State Machine（状态 + 转移）

价值在可恢复：刷新 / pending / RPC 失败 / 模型重试时，系统不忘进度、不重复执行危险动作。submitted 之后锁死，不允许"重跑"。

stateDiagram-v2
    [*] --> draft
    draft --> context_loaded
    context_loaded --> plan_ready
    plan_ready --> simulation_failed
    plan_ready --> waiting_user_confirmation
    waiting_user_confirmation --> cancelled : 人拒绝 / policy 越界
    waiting_user_confirmation --> submitted : 人批准 + 发送
    submitted --> waiting : pending 超时(只查不发)
    submitted --> confirmed
    submitted --> reverted
    waiting --> confirmed
    waiting --> reverted
    simulation_failed --> [*]
    cancelled --> [*]
    confirmed --> [*]
    reverted --> [*]
