# Handbook Feedback

我对 [AI × Web3 School Handbook](https://aiweb3.school/zh/handbook/) 的反馈：错别字、过期内容、概念不清、结构建议。

## 单条 feedback 格式

每条 feedback 一个文件，文件名 `YYYY-MM-DD-短描述.md`，正文模板：

```markdown
# {{短标题}}

- Handbook 页面：{{完整链接，含锚点}}
- 来源 daily：daily/YYYY-MM-DD.md
- 类型：错别字 / 过期内容 / 概念不清 / 结构建议 / 资料补充

## 问题

{{我读到这里时遇到的问题，越具体越好}}

## 建议

{{我建议怎么改}}

## 备注

{{可选：相关讨论、引用、其他链接}}
```

## 反馈原则

- 优先记录会卡住其他学员的问题，而不是个人偏好。
- 引用 Handbook 原文时尽量精确到段落。
- 建议改法越具体越好（直接给改写文本最佳）。
